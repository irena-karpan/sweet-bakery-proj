# Sweet Factory 🍰

## 📋 Про проєкт

**Sweet Factory** — адаптивний вебсайт кондитерської, створений для перегляду
каталогу десертів, ознайомлення з популярними товарами, відгуками клієнтів та
оформлення замовлення.

Проєкт реалізований з урахуванням сучасних принципів адаптивної верстки,
інтерактивності та зручності користування на різних пристроях.

### Основний функціонал

- перегляд каталогу десертів;
- фільтрація десертів за категоріями;
- кастомний select для вибору категорії;
- перегляд популярних десертів у слайдері;
- перегляд детальної інформації про десерт;
- оформлення замовлення через модальне вікно;
- перегляд відгуків клієнтів;
- відображення рейтингу десертів за допомогою зірок;
- слайдер відгуків;
- FAQ з можливістю розгортання запитань;
- повідомлення про успішні та невдалі дії користувача;
- динамічне завантаження даних з API;
- адаптивна верстка для мобільних пристроїв, планшетів та десктопів.

## ⚙️ Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone <посилання-на-репозиторій>
```

### 2. Перехід до папки проєкту

```bash
cd <назва-папки>
```

### 3. Встановлення залежностей

```bash
npm install
```

### 4. Запуск проєкту в режимі розробки

```bash
npm run dev
```

Після запуску Vite надасть локальну адресу, за якою можна відкрити проєкт у
браузері.

## 🔌 Робота з API

Дані для каталогу десертів та відгуків завантажуються динамічно через **REST
API**.

Для виконання HTTP-запитів використовується бібліотека **Axios**.

За допомогою API проєкт отримує:

- список десертів;
- популярні десерти;

- відгуки користувачів;
- дані, необхідні для оформлення замовлення.

## ✨ Інтерактивні елементи

### Категорії десертів

Користувач може фільтрувати десерти за категоріями.

На мобільних та планшетних пристроях використовується кастомний select,
реалізований за допомогою **Choices.js**.

На десктопних пристроях категорії представлені у вигляді кнопок.

### Популярні десерти

Популярні товари відображаються у вигляді слайдера.

Для реалізації використано **Swiper** з підтримкою:

- навігації;
- пагінації;
- адаптивної кількості слайдів;
- перемикання між товарами.

### Детальна інформація про десерт

При виборі десерту користувач може відкрити модальне вікно з детальною
інформацією про товар.

### Форма замовлення

Замовлення оформлюється через модальне вікно.

Користувач заповнює необхідні поля, після чого дані відправляються на сервер.

Для відображення результату операції використовуються повідомлення та модальні
вікна.

### Відгуки

Відгуки користувачів представлені у вигляді слайдера.

Для відображення рейтингу використовується **rater-js**.

### FAQ

Секція поширених запитань реалізована за допомогою **accordion-js**.

Користувач може відкривати та закривати окремі запитання.

### Повідомлення

Для інформування користувача про результат виконання дій використовуються:

- **iziToast** — компактні toast-повідомлення;
- **SweetAlert2** — модальні повідомлення та підтвердження.
