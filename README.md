# Солодка Майстерня

## Про проєкт

**Солодка Майстерня** — адаптивний вебсайт кондитерської, створений для
презентації асортименту десертів та зручної взаємодії користувача з сайтом.

Проєкт дозволяє:

- переглядати каталог десертів;
- переглядати детальну інформацію про продукцію;
- оцінювати товари за допомогою рейтингу;
- переглядати відгуки клієнтів;
- користуватися інтерактивними елементами сайту;
- комфортно переглядати сайт на різних пристроях.

Основна мета проєкту — створити сучасний, зручний та адаптивний вебсайт для
кондитерської з інтуїтивно зрозумілим інтерфейсом.

## Технології

У проєкті використані:

- **HTML5** — семантична структура сторінок;
- **CSS3** — стилізація та адаптивна верстка;
- **JavaScript** — реалізація інтерактивної функціональності;
- **Vite** — збірка та локальна розробка проєкту;
- **Axios** — виконання HTTP-запитів;
- **Accordion.js** — реалізація акордеонів;
- **Swiper** — створення слайдерів та каруселей;
- **MicroModal** — модальні вікна;
- **iziToast** — повідомлення та сповіщення для користувача;
- **SweetAlert2** — інтерактивні модальні повідомлення;
- **Raty.js** — реалізація рейтингових оцінок;
- **CSS Star Rating** — відображення рейтингу у вигляді зірок.

## Адаптивність

Сайт адаптований для різних розмірів екранів:

- 📱 **Mobile** — смартфони;
- 📱 **Tablet** — планшети;
- 💻 **Desktop** — персональні комп'ютери та ноутбуки.

Інтерфейс автоматично підлаштовується під ширину екрана, забезпечуючи комфортну
навігацію та перегляд контенту.

## Запуск проєкту локально

Для запуску проєкту необхідно мати встановлений **Node.js**.

1. Клонувати репозиторій:

```bash
git clone <repository-url>
```

2. Перейти до папки проєкту:

```bash
cd <project-folder>
```

3. Встановити залежності:

```bash
npm install
```

4. Запустити проєкт у режимі розробки:

```bash
npm run dev
```

Після запуску Vite надасть локальну адресу, за якою проєкт можна відкрити у
браузері.

## Збірка проєкту

Для створення production-версії виконайте:

```bash
npm run build
```

Для локальної перевірки зібраної версії:

```bash
npm run preview
```

## Розгортання

Проєкт може бути розгорнутий на сервісах для хостингу статичних вебсайтів,
наприклад **GitHub Pages** або іншому подібному сервісі.

Перед розгортанням необхідно виконати production-збірку:

```bash
npm run build
```
